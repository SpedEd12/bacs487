BearExchange – UNC Student Marketplace

A web application designed for University of Northern Colorado students to buy, sell, and trade items safely within the campus community.

Description

BearExchange is a marketplace platform created for UNC students to exchange textbooks, furniture, electronics, clothing, and other items. The platform is designed to function similarly to Facebook Marketplace, but restricted to verified UNC BearMail users. Key features include browsing and searching listings, detailed item pages, account profiles, seller communication via messaging, and administrative tools for moderating reported items and managing user activity.

The project includes a React frontend, a Node.js backend, and a MySQL relational database. It is built as part of a multi-team academic project focusing on system design, database integration, and full-stack web development practices.
