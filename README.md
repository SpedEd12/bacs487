# 🐻 BearExchange – UNC Student Marketplace

A web application designed for **University of Northern Colorado (UNC) students** to buy, sell, and trade items safely within the campus community.

---

## 📝 Description

BearExchange is a marketplace platform created exclusively for UNC students to exchange **textbooks, furniture, electronics, clothing, and more**. Inspired by Facebook Marketplace, the platform is limited to authenticated UNC students and emphasizes **safety** and **ease of use**.

### Core Features

* Browsing and searching listings
* Viewing detailed item information
* Contacting sellers
* Saving items
* Accessing an administrative dashboard for moderation

### Technology Stack

The project uses a **React frontend**, a **Node.js backend**, and a **MySQL database**. It is developed collaboratively as part of an academic project focusing on full-stack development, backend integration, and system design.

## 🚀 Getting Started

These instructions will get you a copy of the project up and running on your local machine for development and testing purposes.

### Dependencies

The project currently requires:

* **Node.js** (version TBD)
* **MySQL** (version TBD)
* **Git**
* A modern web browser
* Windows, macOS, or Linux

> Additional dependencies will be added as development continues.

### Installing

After cloning the repository, the directory structure is:
bearexchange/ ├── frontend/ ├── backend/ ├── db/ └── docs/

To install project dependencies:

#### Frontend
```bash
cd frontend
npm install
```

#### 2. Backend

```bash
cd frontend
npm install
```
Note: Ensure MySQL is installed and running. Schema files will be added soon in the db/ directory.

### Executing Program
Instructions will expand as additional code is implemented.

#### Frontend
``` bash
cd frontend
npm run dev
```

#### Backend
```bash
cd backend
node src/server.js
```
Note: Additional environment variables and build steps will be added as development progresses.

## 🛠️ Help / Troubleshooting
* Common troubleshooting steps will be documented as the project evolves.
* For early setup issues, please check the following:
* Confirm .env files (for both frontend and backend) are configured correctly.
* Ensure MySQL is running on the correct port.
* Verify ports for the frontend and backend do not conflict with other applications.
* Check that dependencies installed without errors.
